# 모래 마스크 외부 배경 채움 수정

## 원인과 변경

기존 `sand_mask`는 역마스크의 `(0,0)`만 외부 배경의 seed로 삼았다. 모래가 그 모서리를 덮으면 모래 자체를 flood-fill하고 외부를 내부 구멍으로 오인한다. 모래가 영상 양끝을 가로질러 외부 배경을 나눌 때도 seed와 떨어진 외부 영역을 잘못 메운다.

역마스크에 한 픽셀 외부 배경 패딩을 붙이고 패딩에서 flood-fill한다. 밝기 분할·최대 성분 선택·직선 추출·추정기·제어는 그대로다. 현재 모듈은 오프라인 실험 전용이다.
