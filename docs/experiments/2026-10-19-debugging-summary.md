# 2026-10-19 전체 임무 시뮬 디버깅 정리 (지금까지의 실험과 발견)

> **⚠ 정정 안내 (2026-10-19 독립 감사 후):** 이 문서의 해석·원인 귀속·"채택/되돌림" 판정 중 상당수가 감사에서 과장 또는 오류로 확인되었다. 반드시 `2026-10-19-audit-corrections.md`를 먼저 읽고, 충돌하면 그 문서를 따른다. 정량 수치 자체는 대부분 원자료와 일치했다.


작성 목적: 목표(완주 탐색)를 접고 사용자와 함께 디버깅하기 위한 현황 정리. 사실(데이터로 확인)과 가설(미확인)을 분리했다. 상세 표는 `2026-10-19-full-mission-search.md`.

## 1. 한 줄 요약

- 어느 설정에서도 전체 임무를 완주하지 못했다. 가장 긴 폐루프는 63 s(blend, corner370).
- 실패는 하나의 원인이 아니라 연쇄다: **(a) 제자리·코너 회전 중 ORB 손실 또는 yaw 갱신 오염 → (b) ESKF가 yaw·속도 상태를 과신한 채 틀어짐 → (c) 추정만 보는 제어가 로버를 벽 쪽으로 보냄 → (d) 추정 기반 안전 검사가 늦게/엉뚱하게 정지.**
- 지금까지 효과가 확실했던 것은 둘뿐: 회전 중 영상 위치 σ ×4 해제(첫 코너 오차 해결), blend 추종기(24 s대 결정적 ORB 손실 제거).

## 3. 확인된 발견 (데이터 근거)

1. **영상 σ ×4가 첫 코너 오차의 직접 원인**: 오프라인 재생에서 ×1이면 오차가 1/3 이하. (실기 ORB 끊김 관측에서 온 시뮬 휴리스틱이므로 실기 σ는 시뮬만으로 바꾸지 않는다.)
2. **ORB 상대 관측 자체는 정확**: 직진 병진 RMS 0.2~0.35 cm, 회전 0.3~0.5°. 관측을 GT로 바꿔도 오차가 남는다(cy_y45b: 49.8 cm). 원인은 필터 내부.
3. **필터가 병진 residual을 yaw와 gyro bias z로 잘못 흡수**: 전파 yaw는 GT와 2° 안인데 영상 갱신이 yaw를 −8~−14°씩 밀어 누적 −30~−40°. 위치 잔차와 dyaw 상관 −0.78~−0.86. gb_z만 참값 고정하면 최대 오차 40.5→11.4 cm.
4. **필터 가정 잡음이 시뮬 IMU 잡음보다 작다**: gyro 18~36배, accel 8~23배. 속도 σ는 실제 오차의 1/5, tilt σ는 1/12(과신). 게이트(NIS)는 지속 편향을 못 본다.
5. **ORB 손실은 같은 설정에서도 확률적**: 같은 시드·명령에서 ORB pose가 4 s부터 mm~cm 단위로 벌어진다. 손실 시작은 기준 unicycle 3회가 24.0~24.3 s로 일정했지만, blend는 없음/32.6/49 s로 제각각. 따라서 **단일 표본 비교는 믿을 수 없다**(N≥3 필요).
6. **손실 후 IMU 단독은 3 s에 약 38 cm 드리프트**(속도 오차 −0.15~−0.2 m/s, tilt 이중적분 지배). 시뮬 relocalization 대기는 기본 3 s(실기 설정 15 s)이고 손실 대부분이 지도 리셋으로 끝난다.
7. **blend는 ORB 손실을 없앴지만 새 문제**: 저속 구간 yaw 오염, connector에서 GT yaw가 명령을 못 따라가는 런(cz_r2/r3: 몸 기준 병진 방향 θ −75°~−115°, 순수 옆걸음 상태에서 정지), 램프 게이트가 추정 몸 중심 경사만 읽어 허위/미발동.
8. **30° 램프 등판 정체는 지형·마찰 쪽**: 정체 구간 슬립 약 93%(조인트 환산 대비 GT), 앞바퀴만 살짝 올랐다 밀림. 기준 런도 같다. 기본 마찰값은 미확인.
9. **실패 트리거는 대부분 추정 위치의 마스크 거리 0.4~6 mm 부족**(문턱 0.2854 m). 경로가 마스크 경계에 0.9 mm 여유로 붙어 있고, 연결 경로 최대 여유는 시작 셀(0.375 m)이 상한이라 경로 이격으로는 약 4 cm밖에 못 번다. 실제 GT는 칸막이 끝에 1~7 cm까지 접근한 런이 많아 **접촉 위험은 실재**(접촉 센서 기록은 없음).
10. **오프라인 필터 변형(16런 개루프)**: NoiseGyro ×20(악화 0, 최악 94.7→37.4 cm), gyro bias 정지 평균 초기화(yaw 최악 47.8→7.3°), 조합이 가장 좋음. 평균 0 채 σ만 줄이기·위치 σ 0.5 cm는 발산. 폐루프에서는 ×20이 뚜렷하게 재현되지 않음.

## 4. 아직 모르는 것 (미확인)

- ORB 손실의 직접 원인(내부 inlier 수 기록 없음). 정지·저회전에서도 생긴다.
- yaw 오염을 **시작시키는 계기**(저속 코너에서 시작, 벽 접촉은 아님).
- 시뮬 ORB 이미지에 복구 대기 패치가 들어있는지(없으면 대기 시간 옵션은 무의미).
- 시뮬 상의 기본 마찰값, RL 정책이 램프에서 하는 일, IMU 생성기(GT 미분)의 잡음 특성이 실기와 얼마나 같은지.
- RL이 오차를 키우는지(OFF 표본 1개), 조인트 순열/FW 원점 오차(−0.0183 m, 별도 worktree)의 영향.
- 실제 접촉 발생 여부(센서 기록 없음).

## 5. 이번 세션에서 내가 만든 오류 (재발 방지 포함)

- 스크립트 변수 확장 실수 2회(인용 없는 heredoc → 빈 라벨 `rm -rf`로 서버 `site_mission` 전체 삭제, `pgrep -f`가 자기 자신 종료). `rm -rf` 제거, 빈 라벨 거부, PID로만 종료.
- `cz_b375`가 corner375가 아니라 corner370 번들로 돌았다(번들 인자 수정이 한 스크립트에만 반영). 해시로 확인·정정.
- 단일 표본으로 결론을 낸 서술을 여러 번 했고(cy_y45a 등) 반복 실험으로 정정.
- `imu_realism` 대입 누락 NameError(실제 실행하는 회귀 테스트 추가).

## 6. 함께 디버깅할 후보 (제안, 우선순위 순)

1. **yaw 오염의 시작 순간을 프레임 단위로 추적**: cz_b370 corner B(20~30 s)에서 영상 갱신마다 yaw 수정량, 잔차, K 이득, gyro bias를 찍어 오염이 시작되는 갱신을 찾는다. 오프라인 재생으로 가능(서버 불필요).
2. **IMU 생성기 검증**: GT를 미분해 만든 IMU와 realism 잡음 중 어느 쪽이 필터 가정과 어긋나는지, 정지 구간 잡음 스펙트럼을 실기 정지 기록과 비교.
3. **ORB 손실의 원인 분리**: inlier 수·추적 map point 수를 프레임마다 기록(동작 불변)하고 같은 설정 N≥5 반복으로 손실 확률 분포를 측정.
4. **ORB 손실 시 처리**: 영상 미수용 0.3 s 초과 시 회전 정지 / 영속도·엔코더 속도 관측(오프라인 재생으로 먼저).
5. **RL 영향 분리**: OFF 쪽을 N≥3 반복.
6. **마찰·램프**: `--mu` 스윕으로 30° 정체가 지형인지 마찰인지 확정.
