# 명시적 직각 연결 경로 구현 계획

**Goal:** 승인된 직각 코너 경로 비교를 위해 임무에 지정한 출발→갈림길 점열을 저장·복원하고 실행기에 그대로 전달한다.

**Architecture:** `SiteMission(..., connector_waypoints=None)`를 추가한다. 미지정이면 기존 A*·직선 단축을 그대로 사용한다. 지정하면 점열의 형상·유한성·끝점·중복 및 기존 지도 안전 검사를 통과시킨 후 복사본을 반환한다. 임무 JSON에 지정된 경우에만 같은 이름의 선택 필드를 저장한다. `MissionRuntime`은 기존 `mission.connector()` 호출로 전달받는다.

**Tech Stack:** Python 3.10, numpy, 기존 `.venv-mapping`, pytest. 시뮬 실행은 기존 server CLI.

## 요구사항과 검증

- [x] 기존 테스트로 깨끗한 기준 상태 확인(16 passed).
- [x] 명시적 안전 점열 보존·복사, runtime 점열 전달, 파일 왕복을 검증하는 실패 테스트 작성.
- [x] 잘못된 모양·NaN·잘못된 끝점·중복·안전 점 사이 금지 구간을 거부하는 실패 테스트 확인(신규 13개 RED 후 GREEN).
- [x] `site_mission.py`만 최소 수정. 미지정 JSON과 기존 임무 경로/설정은 변경하지 않는다.
- [x] 신규 및 기존 mission/runtime/지도 관련 테스트 85 passed. 별도 읽기 전용 리뷰에서 수정할 문제 없음.
- [x] 기존 임무 번들을 새 출력 폴더로 복사하고 `connector_waypoints`만 추가한다. 동일 site_identity·기존 routes·settings를 확인한다.
- [ ] 안전 반경 0.30 m, 정상 경사 한계, 속도·RL·IMU·시드·시작 오차·지연은 유지한다. ×1 설정에서 connector만 바꾼 60 s 실행 후 전체 임무로 확대한다.

## 경계

실기/Pi 명령, 추정기나 RLC 융합, 안전 반경 완화, 삭제 명령과 기존 결과 덮어쓰기는 범위 밖이다. 최종 목표 완료에는 접촉 없는 전체 임무와 최종 위치 오차 5 cm 미만, RLC의 현실 검증 근거가 별도로 필요하다.

## 확인 기록

기존 16개 통과 → 신규 13개 실패(지원되지 않는 생성자 인자 및 unsafe JSON 미검출) → 최소 수정 후 신규+기존 29개 통과 → runtime/replay/carrot/site_map까지 85개 통과. 임무 번들 두 개는 원본 대비 `connector_waypoints`만 바뀌었고 모두 기존 지도 검증을 통과했다. 독립 코드 검토에서도 실제 요구 위반은 발견되지 않았다. 시뮬 성능은 이 테스트로 주장하지 않는다.
