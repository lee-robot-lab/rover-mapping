# 기준 맵·경기 STL 보정 진행 현황 — 2026-10-14

전체 목표는 현재 장소의 스캔을 경기 STL 대신 쓰는 고정 기준 맵으로 만들고, 별도 주행에서 형상에 맞춰 누적오차를 보정하며 지형 층/costmap을 검증하는 것이다. 현재는 영상 기반 매핑 경로와 촬영 안내를 확보했고, 1단계 후반~2단계에서 기준 데이터의 연속성·정확도를 높이는 중이다. 3~4 및8의 일부를 선행 구현했다고 앞단 검증이 완료된 것으로 세지 않는다.

| 단계 | 현재 상태 |
|---|---|
|1 실기 원본 기록|실제 Pi에서 좌우IR/depth/보정/시각을 노트북에 저장·재생. STM/조종 통신 확인. IMU·encoder동시기록 미연결. 영상 누락/큐drop 정합 및 포화 재현, 단계별 계측 구현. 최초 병목의 새 실기 확인 필요|
|2 믿을 수 있는 기준3D맵|실제 ORB+TSDF mesh/cloud 생성·뷰어 완료. map분리/누적오차/실측거리·단차 검증과 추가최적화 미완료|
|3 지형 층|높이/경사/거칠기/단차/관측 통계 코드와 합성검증 있음. 실제중력정렬·지면분할·실측 검증 전|
|4 로버 costmap|초기cost/unknown/원형여유 코드 있음. 로버제원·실제통과조건 보정과실기 검증 전|
|5 스캔/STL 공통입력|미연결|
|6 별도주행 형상보정|일부기존STL벽/방향 실험 있음. 일반스캔mesh기준 보정 pipeline 미연결|
|7 보정·지형 효과 실기평가|미실시|

|9 경기STL 동일흐름|미실시|

## 바로 다음 순서: 정확도·안정성 우선

1. 추적 손실 직전 leftIR0.93초/depth3초 입력 공백은 큐drop과 정합하고, 포화/stream별 비대칭 누락을 재현했다. Pi·노트북 계측과 최종 counter 저장 수정을 완료했으므로 새 촬영에서 압축·전송·저장 중 최초 병목을 찾고 줄인다. 전체frame수/추적성공률만으로 안정성을 판단하지 않는다.
2. IMU·encoder를 카메라와 함께 노트북에 기록한 뒤 실제샘플시각·주기·clock·축·장착변환·bias/noise를 확인한다. 현재50Hz SPI telemetry와 실제IMU acquisition을 동일한것으로 가정하지 않는다. 확인 전 관성융합을 켰다고 표시하지 않는다.
3. 같은 입력에서 영상단독/관성융합/필요시CLAHE·점선을 비교하고, 알려진거리/단차/시작점재방문·중복벽으로 지도를 평가한다. 최종선택된 기준맵을 고정한 뒤 별도주행 보정 단계로 넘어간다.

지형/costmap이있는것과실제물리값을정확히얻는것은구분한다. 관측색/voxel1cm/추적98.75%를정밀도보증으로쓰지않는다. 실시간 격자는 initial optical X-Z·중력미정렬이며 IMU fusion미적용.

COLMAP은 촬영 후 기준 맵 pose/형상 비교 후보이며 아직 설치·실행·통합하지 않았다. 동일 원본 baseline 재생도 결과가 변했고 특징 수 2400에서도 주 맵 분리가 유지돼 ORB 기본 설정은 유지한다. [원인 조사·계측·검증 보고](2026-10-14-input-gap-investigation.md).
