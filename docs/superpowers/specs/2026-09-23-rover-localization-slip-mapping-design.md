# 로버 위치추정·슬립 지도·경로계획 설계안

상태: 사용자 검토용 설계안 (2026-09-23)

## 목적과 경계

목적은 규사 6호가 깔린 `gyusa+.stl` 지형에서 로버의 침하·흔들림이 생겨도 무조명 passive stereo와 IMU로 6DoF **시험장 국소** 위치를 추정하고, 바퀴 슬립 경험을 지형 지도에 남겨 안전한 경로를 선택할 수 있는지 검증하는 것이다. `gyusa+` STL의 바닥·벽 형상과 바닥 경사는 변하지 않는 사전 정보다. 그 위의 모래 표면·바퀴자국·슬립 경험은 관측으로 갱신한다. 학습된 시각 모델, 보조 조명, IR projector, 시뮬레이터의 정답 depth·pose를 추정기 입력으로 사용하지 않는다. 달 전역 좌표계에서 드리프트 없는 위치추정이나 실제 달 표토 물성의 정량 재현은 첫 범위가 아니다.

사용자가 정한 로버 외형 한계는 바퀴와 카메라를 포함해 **30 × 30 × 20 cm**다. 기구 설계가 진행 중이므로 초기 소프트웨어는 로버 URDF 없이 검증한다. 팀 URDF는 마지막 통합 단계에서 우선 연결한다. 그때까지 모델이 없으면 위 외형 한계의 단순 4륜 모델을 만든다. 팀 URDF가 한계를 넘더라도 조용히 축별 스케일을 변경하지 않고 치수와 질량·관성 재검토를 요청한다.

## 단계 분리와 데이터 흐름

1. **모델 독립 시험 데이터:** 정답 6DoF 궤적에서 IMU·바퀴 회전·조향각을 생성하고, 지정한 구간에 전진/횡방향 슬립·영상 관측 소실·시간 오차를 주입한다. 추정기 시험에는 정답 pose 대신 오차와 covariance를 가진 독립 pose 입력을 제공하고, 정답은 평가에만 쓴다. 이는 추정·지도 소프트웨어의 논리 검증 자료이며 규사 물리 실험 자료가 아니다.
2. **센서 시험:** 로버 없이 `gyusa+`의 벽·바닥 안에 모래 표면을 놓고 카메라의 6DoF 경로를 움직여 좌·우 영상 및 IMU를 만든다. 고정 표면으로 영상·시간동기 경로를 확인한 뒤 입자층 표면으로 재시험한다. 자연광 조건과 카메라 흔들림을 바꾸며 projector를 끈 passive stereo matching에서 생성된 depth·point cloud의 유효율과 오차를 평가한다. 렌더러의 이상적 depth는 평가기에만 보낸다. 이 단계에서 바퀴–모래 접촉을 검증했다고 주장하지 않는다.
3. **위치추정:** 동기화된 좌·우 영상과 IMU로 `odom → base_link` 6DoF pose, twist, covariance, 추정 상태를 출력한다. 최초 비학습 기준 구현은 [OpenVINS](https://github.com/rpng/open_vins)의 stereo+IMU 경로를 별도 프로세스로 실행해 결과를 받는다. OpenVINS의 ROS 2 지원은 공개되어 있지만 실제 Humble/선택한 Isaac Sim 버전의 실행 호환성은 첫 통합 점검으로 확인한다. OpenVINS는 GPL-3.0이므로 코드 복사·배포 범위는 라이선스를 확인하기 전까지 확장하지 않는다. 바퀴 encoder는 슬립 검출 기준 pose를 만들 때 무조건적인 no-slip 관측값으로 융합하지 않는다. 알려진 시작 pose와 STL의 **카메라에 실제 보이는 고정 형상**을 사전 정보로 사용해 `map → odom` 보정을 시험한다. 모래로 가려진 바닥을 카메라가 직접 본 것처럼 STL에 정합하지 않는다. 고정 기준이 시야에 없으면 보정을 생략하고 uncertainty를 증가시킨다.
4. **슬립 추정:** 각 바퀴의 측정 회전속도와 추정 차체 twist에서 계산한 해당 바퀴 위치의 지면 방향 속도를 비교한다. 조향각과 실제 바퀴 위치, 그리고 존재한다면 서스펜션 변위를 반영한다. 속도가 매우 낮거나, 카메라 관측 불량으로 독립 이동 추정이 부정확하거나, 바퀴 접촉이 확실치 않을 때는 숫자 대신 `unknown` 또는 낮은 신뢰도를 낸다. 출력은 접촉 패치의 직접 측정치가 아닌 **바퀴별 유효 슬립 추정**이다.
5. **지도 및 경로계획:** STL에서 바닥 높이·경사와 벽을 고정 prior layer로 만든다. stereo point cloud와 추정 pose로 그 위의 모래 **표면** 높이와 단차를 별도 층에 갱신한다. 슬립 경험과 관측 신뢰도도 분리해 누적한다. 경로계획은 고정 바닥 경사, 현재 모래 표면의 단차·장애물·미관측 위험, 진행 방향별 슬립 경험을 사용한다. 다음 방문 시 새 관측으로 재계획한다.
6. **마지막 물리 통합:** 팀 URDF 또는 대체 4륜 모델을 `gyusa+`의 변형 모래층에 넣어 카메라 흔들림, depth, 6DoF 위치, 슬립, 경로의 종단 성능을 검증한다. 입자 모델을 실제 규사 견인력의 정답으로 간주하지 않는다.

### 첫 센서 시험: 고정 모퉁이 가시성·정합

로버 모델 없이 카메라를 시험장 내부의 여러 경로로 이동시키며, `gyusa+`의 벽·모퉁이 중 모래 위로 실제 노출되는 부분이 좌우 영상과 stereo point cloud에 얼마나 남는지 측정한다. 직선 이동, 벽을 비스듬히 보는 이동, 코너 진입·이탈을 포함하고 카메라 높이·방향, 흔들림, 모래 표면 높이, 자연광 방향을 바꾼다. 최종 카메라 사양이 정해지기 전 결과는 시험에 사용한 임시 광학 설정에만 유효하다.

STL 정합 시험에서는 추정 pose와 그 uncertainty로 예상되는 **가시 고정 형상**만 후보로 사용한다. 관측 point cloud에서 모래로 가린 바닥이나 가려진 벽을 정합 근거로 채우지 않는다. 동일한 시작 오차를 준 상태에서 `prior 보정 없음`과 `가시 고정 형상 보정`을 비교해, 프레임별 고정 형상 관측 비율, 정합 잔차, pose 오차 및 잘못된 보정 빈도를 기록한다. 비슷하게 생긴 코너가 반복되거나 한쪽 벽면만 보여 위치가 유일하게 정해지지 않으면 보정을 거부하고 VIO/IMU의 pose와 uncertainty를 유지한다. 이 시험은 사전 STL이 유용한 **관측 조건**을 찾는 것이며, 모퉁이가 많다는 이유만으로 항상 정합 가능하다고 가정하지 않는다.

소프트웨어의 입력/출력 경계는 ROS 2 Humble의 `Image`, `CameraInfo`, `Imu`, `JointState`, `Odometry`, `PointCloud2`와 `TF`를 기준으로 둔다. 각 기록에는 simulation time, 프레임, 보정값 버전, 실행 조건을 남긴다. 정답 pose·휠 접촉 상태·이상적 depth는 **평가 채널**에만 두고 런타임 추정/계획 경로와 분리한다. `map` 프레임은 STL 시험장 좌표에 고정하고 시작 pose에는 실제로 아는 만큼의 uncertainty를 부여한다. STL 자체는 사전 설계 정보이며 시뮬레이터의 매 시점 정답 상태와 구분한다. 달 전역 재위치추정·loop closure는 후속 범위다.

## 슬립 정의와 품질 관리

바퀴 `i`의 진행 방향 단위벡터를 `t_i`, 반지름을 `R_i`, 회전속도를 `ω_i`, 추정 바퀴 중심의 지면 접선 속도를 `v_i`라 두면 `d_i = R_i ω_i - t_i · v_i`를 전진 슬립 속도로 기록한다. 회전 중 차체 각속도와 바퀴 중심 오프셋을 포함해 `v_i`를 계산한다. 정규화된 슬립률은 속도가 설정한 하한보다 클 때만 계산한다. 바퀴 수직하중·유효 반지름·접촉 조건이 불확실하면 그 불확실성을 결과에 전달한다. 횡방향 밀림은 별도 성분으로 두며 전진 슬립률에 섞지 않는다.

visual-inertial pose의 covariance, stereo 대응점/feature 유효율, IMU·영상 시간 정렬, 바퀴 측정 누락을 함께 기록한다. 시각 관측이 사라진 동안 IMU/encoder로 단기 예측은 가능하지만 슬립을 독립적으로 정밀 계측했다고 해석하지 않는다. 모래에서 위치추정이 실패한 구간은 `고슬립`이 아니라 `슬립 미확인`으로 표시한다.

## 지도 표현

초기 지면 지도는 2.5D 격자이며, 격자 크기는 첫 검증에서 2 cm로 시작하고 센서 분해능과 연산량을 측정해 조정한다. 고정 prior layer를 주행 결과로 덮어쓰지 않는다. 각 셀의 필수 값은 다음과 같다.

| 분류 | 필수 층 |
|---|---|
| 고정 prior | STL 바닥 높이·경사, 벽·고정 장애물, 형상 출처 |
| 관측 표면 | 모래 표면 높이 평균·분산, 바닥 대비 모래 두께 추정, 바퀴자국·단차, 새 장애물 및 미관측 마스크 |
| 주행 경험 | 진행 방향 8구간별 전진 슬립 통계, 횡방향 밀림/정체 사건 수, 관측 횟수, 마지막 관측 시각 |
| 신뢰성 | 위치추정 covariance 기반 품질, stereo 유효율, 슬립 추정 유효 여부·분산 |

원시 표본에는 바퀴 ID, 조향각, 주행 속도, 진행 방향, 사용한 pose와 그 불확실성을 보존한다. 모래 표면 높이 갱신에는 depth 오차와 pose covariance를 함께 반영한다. 모래 두께는 표면과 STL 바닥의 차이라는 **간접 추정치**이며 보이지 않는 바닥을 실측한 값이 아니다. 격자에는 조건별 집계값을 저장해 단일 표본을 지형의 불변 물성처럼 사용하지 않는다. 재주행으로 바퀴자국이 생기면 표면 높이만 새 관측으로 갱신하고 관측 시각을 보존한다. 아직 보지 않은 셀은 `슬립 0`이 아닌 `unknown`이다. 초기 planner는 A*의 방향별 edge cost에 고정 경사·관측 표면 위험·관측 슬립·불확실성 비용을 적용한다. 바닥 STL이 알려져 있어도 **모래 표면이 전혀 관측되지 않은 셀**은 첫 검증에서 진입 불가로 둔다.

## 검증 관문

| 관문 | 실패를 판별할 시험 |
|---|---|
| 데이터 계약 | 서로 다른 프레임·역순 timestamp·누락된 바퀴 값을 거부하거나 명시적 `unknown`으로 처리; 정답 채널이 추정기 입력으로 연결되지 않음 |
| 위치추정 | 하드 바닥/카메라 정지/흔들림/낮은 지형 질감에서 ATE·RPE·pose covariance와 관측 유효율 기록; 모퉁이 가시성·정합 시험에서 `prior 없음`과 비교하고 반복 코너·단일 평면·모래 가림 조건의 모호한 정합을 거부; 고정 STL 형상이 보일 때만 prior 정합으로 `map → odom` 보정; 모래만 보이거나 관측이 소실되면 잘못된 고신뢰 보정을 출력하지 않음 |
| 슬립 | 주입된 좌우·전진·횡방향 슬립을 구분; 저속·비접촉·VO 소실은 유효하지 않은 슬립으로 표시; 바퀴 데이터를 기준 pose에 순환 융합하지 않음 |
| 지도 | 같은 경로 반복에서 고정 바닥·경사가 불변이고 모래 표면·슬립 통계만 갱신됨; 미관측/저신뢰 영역을 안전한 무슬립 구역으로 바꾸지 않음 |
| 계획 | 동일 시작·목표에서 거리 전용 경로와 위험 비용 경로를 비교하고 성공률·정체·재계획 시간을 기록; 통로가 없으면 경로 없음으로 종료 |
| 물리 통합 | URDF 외형·관절·센서 TF 검사, 바퀴–모래 상호작용과 카메라 pose 연결, stereo depth/point cloud 품질, 슬립 추정 대비 시뮬레이션 정답을 별도 평가 |

정량 통과 문턱은 실제 카메라 설정과 팀 URDF의 관절·하중 정보가 들어온 뒤 사전 등록한다. 그 전의 통과는 위 논리 불변조건과 기준선 대비 측정 결과를 모두 남겼다는 뜻이지 실물 규사 성능을 보증한다는 뜻이 아니다.

## 구현 계획의 분할

이 설계는 한 번에 구현하지 않는다. 후속 구현 계획은 (A) 데이터 계약·재생 시험, (B) stereo/IMU 위치추정과 센서 품질 평가, (C) 슬립 추정과 경험 지도, (D) 위험 경로계획, (E) 마지막 URDF·모래 통합으로 나눈다. 각 작업은 이전 단계의 기록 데이터를 소비해 독립적인 시험 결과를 내야 한다. 로버 모델 제작은 (E)에서 팀 URDF가 없을 때만 수행한다.
